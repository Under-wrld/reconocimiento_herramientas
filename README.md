# Detección de Herramientas en Imágenes 

Este proyecto usa Flask y TensorFlow para detectar herramientas (destornillador, martillo y llave) en imágenes, usando un modelo CNN.

## Instalación

Usando el bash, ejecutar:
pip install -r requirements.txt

## Script actualizar_dataset_desde_internet.py
El script se usa para descargar imagenes de internet y categorizarlos, evitando repetir imagenes y descartandolas sies que existen repetidas.
